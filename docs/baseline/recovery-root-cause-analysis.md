# Phase 0 Recovery Root-Cause Analysis

Date: 2026-06-08

This document records the acceptance defects confirmed before recovery changes. A green existing
test is not treated as proof when the test does not exercise the production implementation.

## Recovery Rule

The recovery implementation must make each gate fail closed. Unsupported observations are recorded
as `known_gap` with owner and follow-up; they are never converted into `passed` records.
